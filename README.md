# 🎮 Past4

> **It's past 4. Time to play.**

Past4 is a full-stack web application where friends can create private rooms, connect instantly, and enjoy quick browser-based multiplayer games together. Inspired by the idea that once it's past **4 PM**, it's time to unwind, laugh, and play.

Whether you've just finished classes, wrapped up work, or simply want to spend time with friends, Past4 makes it easy to hop into a room and start playing—no downloads, no complicated setup.

---

## ✨ Features

- 🎮 Quick multiplayer browser games
- 👥 Create and join private game rooms
- 💬 Real-time room interactions
- 🔐 Secure user authentication
- 🏆 Match history and leaderboards *(Planned)*
- 📱 Responsive design for desktop and mobile
